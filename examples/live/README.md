# STM32G431CB

Originale ST-Registerheader mit CMSIS-Abhängigkeiten; kein HAL/LL.

Beispielverdrahtung: PB1 → Vorwiderstand → LED → GND. Vor dem Flashen mit der eigenen Platine vergleichen.
HSI16 als Reset-Takt.

Debug/Live: Debug-Profil bauen und passende Firmware flashen. USB-Funktionen sind noch nicht am Referenzgerät abgenommen.
