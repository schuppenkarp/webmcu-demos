# 05 · UART-Bibliothek · USART1 Echo

USART1/2/3, UART4 und LPUART1. 8N1 mit PCLK, einfache Textausgabe und nicht blockierende Byte-API. Pins separat konfigurieren. Pollbudget ist kein Millisekunden-Timeout.

Bibliothek 1.0.0 unter lib/. Quelltext bearbeiten oder Projekt → Bibliotheken öffnen.
Die verwendeten Registerheader sind von ST. Keine HAL und kein Arduino.
Software geprüft; physische Abnahme am Board steht noch aus.
